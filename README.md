## 📚 Topics Covered

### Basics
- **Comments** - Single and multi-line comments
- **Variables** - var, let, const declarations
- **Data Types** - Primitives and reference types
- **Operators** - Arithmetic, logical, comparison

### Control Flow
- **Loops** - for, while, do-while, for-in, for-of
- **Conditionals** - if-else, switch statements

### Functions & Scope
- **Functions** - Declaration, expression, arrow functions
- **Scope** - Global, function, block scope
- **Hoisting** - Function and variable hoisting
- **Closures** - Understanding closure concept

### Advanced Concepts
- **Objects** - Object creation, properties, methods
- **Destructuring** - Array and object destructuring
- **Rest Parameters** - Using ... operator
- **call(), apply(), bind()** - Function method manipulation
- **this Keyword** - Context binding

### Data Manipulation
- **Strings** - String methods and manipulation
- **Deep Copy** - Copying objects deeply
- **Literals** - Template literals and object literals

### Asynchronous JavaScript
- **Synchronous Code** - Blocking operations
- **Promises** - Promise creation and handling
- **Async/Await** - Modern async programming

### Error Handling
- **Try-Catch-Finally** - Exception handling patterns

### Input & Output
- **Inputs** - User input methods
- **Outputs** - Console logging and DOM manipulation

## 🎓 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Yogesh7564/Javascript-CLASS.git
   cd Javascript-CLASS
   ```

2. **Open files in your editor**
   - Use VS Code, Sublime Text, or your preferred editor
   - View HTML files in a web browser
   - Run JavaScript files with Node.js or browser console

3. **Explore examples**
   - Start with the basics (Comments, Variables, Data Types)
   - Progress to Functions, Objects, and Scope
   - Move on to advanced topics (Closures, Promises, Async/Await)
